# Data access and redistribution

Original GHS microdata, household identifiers, row-level analytic files, and raw questionnaires/manuals are not redistributed in this package. The source manifest gives official catalogue locations and source-file checksums from the private Stage 3 snapshot. Researchers must obtain the data through the provider's terms, retain it in a restricted location, and use the code locally. Aggregate benchmarks, code, documentation, and generated figure assets are included for verification and review.
