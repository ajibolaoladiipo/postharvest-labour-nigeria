# Harmonisation rules

The common cross-wave task core is shelling/threshing/peeling, drying, cleaning, and processing. Wave 5 sorting and supervision remain wave-specific. Task flags are multiple response and must never be made to sum to 100%.

Crop-specific interpretation remains quarantined for non-harmonised codes identified in the Stage 3 source audit. The code preserves source task structures rather than forcing false cross-wave equivalence. Cross-wave comparisons describe observed distributions under differing coverage and instrument conditions; they do not identify behavioural change.
